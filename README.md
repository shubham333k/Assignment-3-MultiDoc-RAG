## Note for Assignment 3 Submission

This project was originally developed by me as a multi-document Retrieval-Augmented Generation (RAG) system. It fully satisfies all the requirements of Assignment 3, including:

- Uploading multiple PDF documents
- Natural language question answering
- Context-aware and grounded responses using LLM
- Source references / citations
- Handling of unavailable information
- Conversational memory for follow-up questions

Although the original domain of this project is healthcare, the underlying architecture is general-purpose and works with any type of PDF documents (technical reports, business documents, policies, operational manuals, etc.).
